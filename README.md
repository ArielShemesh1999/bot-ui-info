## About

Bot-UI is a personal AI workspace where a team of specialized agents — email, calendar, tasks, marketing, WhatsApp — collaborates behind a single chat interface. A master orchestrator decides when to delegate and when to ask. Voice mode, persistent memory and Obsidian sync make it feel less like a chatbot and more like a colleague who actually remembers you.

### Sections

| Section | What it shows |
| --- | --- |
| **Chat** | Single conversational entry point with the orchestrator. |
| **Agents** | Specialized bots for email, calendar, tasks, marketing, WhatsApp. |
| **Memory** | Persistent context across sessions, with Obsidian vault sync. |
| **Voice** | Real-time voice mode — talk and listen, not just type. |
| **Persona** | Customizable tone, voice and personality. |
| **Skills** | Live skills library — add or remove capabilities on the fly. |
| **Activity** | Activity log — every agent action visible and auditable. |
